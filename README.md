# HEISENBERG AUTO GALLERY

A modern and responsive car dealership website built with HTML, CSS, and JavaScript. Heisenberg Auto Gallery provides visitors with a convenient way to explore available vehicles, view vehicle details, and make enquiries.

## About the Project

Heisenberg Auto Gallery is a car dealership website designed to showcase available vehicles in an organized and user-friendly interface.

The website allows visitors to browse vehicles, filter listings, view individual vehicle information, and contact the dealership through an enquiry form.

## Features

- **Vehicle Listings:** Displays available vehicles with their details.
- **Vehicle Filtering:** Filter vehicles by make, model, price, and location.
- **Search Functionality:** Search for vehicles using the search field.
- **Vehicle Details Modal:** View additional information about a selected vehicle without leaving the page.
- **About Us Section:** Provides information about the dealership.
- **Financing Section:** Introduces vehicle financing information.
- **Contact Section:** Allows visitors to submit enquiries through a contact form.
- **Interactive Contact Form:** Displays a personalized confirmation message after submission.
- **Responsive Design:** CSS styling supports different screen sizes.

## Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layout, animations, and responsiveness.
- **JavaScript** – Vehicle filtering, search functionality, modal interactions, and contact form behavior.
- **Font Awesome** – Icons used throughout the website.

## Getting Started

To run this project on your computer:

1. Clone the repository:

     </bash>
   git clone YOUR-REPOSITORY-URL

2. Open the project folder:

     
     </bash>
   cd HEISENBERG-AUTO-GALLERY

3. Open the folder in Visual Studio Code:

    </bash>
   code .

4. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
